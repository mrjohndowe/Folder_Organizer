FOLDER ORGANIZER

Folder Organizer is a Windows desktop utility that helps you review and organize files into folders using built-in and custom file-extension rules.

GETTING STARTED
1. Start Folder Organizer from the Start menu or desktop shortcut.
2. Select the folder you want to organize.
3. Choose Scan to review the proposed file moves.
4. Select the moves you want to apply.
5. Choose Apply Changes and confirm.

SAFETY
Folder Organizer is designed to move files, not delete them. Review every proposed change before applying it, and keep backups of important files.

HISTORY AND UNDO
Open History to review completed organization runs. Select a run and use Undo Selected Run to restore files moved by that run when possible.

UPDATES
Use Check Updates in the application to manually look for a newer version.

UNINSTALLING
Open Windows Settings, choose Apps, find Folder Organizer, and select Uninstall.
