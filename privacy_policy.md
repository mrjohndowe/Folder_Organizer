# Privacy Policy

**Effective Date: September 21, 2026**

This Privacy Policy describes how **Folder Organizer**, developed by **Mr John Dowe**, handles information when you use the application.

## Information We Collect

Folder Organizer does **not collect, transmit, sell, rent, or share personal information**.

The application is designed to operate locally on your Windows computer. Folder Organizer may access files and folders that you specifically choose in order to scan, preview, organize, and move files.

File contents and personal information contained within those files are not uploaded to or transmitted to the developer or any external service.

## File and Folder Access

Folder Organizer requires access to files and folders selected by the user in order to provide its organization features.

The application may process information such as:

- File names
- Folder names
- File extensions and types
- File locations
- File sizes
- File modification dates
- Organization rules and preferences

This information is processed locally on your device and is not transmitted to the developer.

## Local Application Data

Folder Organizer may store application settings, organization preferences, ignored files or folders, and operation history locally on your computer.

The application may use a local SQLite database to maintain this information.

This data remains on your device unless you manually remove it or uninstall the application.

## File Operations

Folder Organizer may move or reorganize files according to actions approved by the user.

The application includes a preview system so users can review proposed changes before applying them.

Folder Organizer is designed not to delete user files as part of its normal organization process.

Users remain responsible for reviewing proposed file operations before applying them.

## Internet Access

Folder Organizer does not require your files or folder information to be transmitted over the Internet in order to perform its primary functions.

If future versions introduce optional online features, this Privacy Policy will be updated before those features are released.

## Third-Party Services

Folder Organizer does not sell or provide user information to advertisers, data brokers, or other third parties.

The application does not use personal information for advertising or behavioral tracking.

## Children's Privacy

Folder Organizer does not knowingly collect personal information from children.

Because the application does not collect personal information from users, no personal information from children is intentionally collected or stored by the developer.

## Data Security

Because Folder Organizer performs its primary processing locally, file and folder information normally remains on the user's own computer.

Users should maintain appropriate backups of important files before performing large file organization operations.

## Data Retention

Folder Organizer does not maintain a remote database containing user information.

Locally stored settings, history, and application data may remain on the user's computer until they are cleared by the user or the application is uninstalled.

## Your Choices

Users control which folders and files Folder Organizer is allowed to process.

Users may stop using the application at any time and may remove locally stored application data by uninstalling Folder Organizer or deleting its local application data.

## Changes to This Privacy Policy

This Privacy Policy may be updated if Folder Organizer's features or data-handling practices change.

Any updated version will include a revised effective date.
