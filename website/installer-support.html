INSTALLER SUPPORT

Installer support and exit codes

Folder Organizer uses an Inno Setup EXE installer. For silent installations, use the following installer parameters: 

/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CLOSEAPPLICATIONS

Exit codes

Exit code Meaning
0 Installation completed successfully.
1 The installer failed to initialize.
2 The user cancelled before installation began.
3 A fatal error occurred while preparing installation.
4 A fatal error occurred during installation.
5 The user cancelled during installation.
7 The installer cannot proceed with installation.
8 The installer cannot proceed until the system is restarted.
